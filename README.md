# Riverkeeper · browser edition

**[Play Riverkeeper online](https://dissanayake41.github.io/riverkeeper-play/)** — play as a guest or create an account for saved campaigns and shared rankings.

A 24-month Mahaweli basin management game. Open the GitHub Pages website to play. Guest progress saves in this browser. Sign in for cloud campaigns and a shared leaderboard; ranked actions and scores are verified by the Supabase game service.

The game uses educational scenario rules, not a calibrated Mahaweli SWAT+ simulation. The model page displays saved reference experiments only. Asset licenses and sources are retained with the assets.
