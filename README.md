# Riverkeeper · browser edition

**[Play Riverkeeper online](https://dissanayake41.github.io/riverkeeper-play/)** — no download or sign-in required.

A 24-month Mahaweli basin management game. Open the GitHub Pages website to play. Progress and scores save in each browser; no online accounts or shared leaderboard are provided here. The separately hosted account server is required for verified rankings.

The game uses educational scenario rules, not a calibrated Mahaweli SWAT+ simulation. The model page displays saved reference experiments only. Asset licenses and sources are retained with the assets.
