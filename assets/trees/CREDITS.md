# Tree foliage

Leaf colour and alpha maps from **Tree Small 02**, by **Rico Cilliers**, Poly Haven.

- Asset and CC0 license: https://polyhaven.com/a/tree_small_02
- Colour: https://dl.polyhaven.org/file/ph-assets/Models/jpg/1k/tree_small_02/tree_small_02_leaves_diff_1k.jpg
- Alpha: https://dl.polyhaven.org/file/ph-assets/Models/png/1k/tree_small_02/tree_small_02_leaves_alpha_1k.png

Downloaded 6 October 2026. Original 1K texture files are unchanged. The game samples an individual leaf region using geometry UV coordinates; it does not display the whole padded atlas on a card. Tree branches and placement are authored in `mahaweli-trees.mjs`; the source high-polygon tree model is not included. Trees are illustrative broadleaf forest symbols and are not a botanical species map of Mahaweli.
